# Geospatial ML

Machine learning on spatial data: land-cover classification, spatial
clustering (DBSCAN), and non-spatial value outlier screening.

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python -m src.train --input data/sample.geojson
```
